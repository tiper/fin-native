# v0.2.1 — Jellyfin remote control, library sorting, fuller library pages, Filmography, and PlxNative 0.10.1

This release brings PlxNative 0.10.1's fixes to FinNative and adds Jellyfin features finished since 0.2.0: other Jellyfin clients can control FinNative, libraries can be sorted, a library's page carries more shelves, shelves scroll past their first cards, and a person's page lists their Filmography. Playing and paused reports reach your server again. It follows 0.2.0, which was cut on 2026-11-13.

It is built on PlxNative 0.10.1 ([7b16697](https://github.com/GLinnik21/plx-native/commit/7b16697ca0a2875a329464aa463195daf137eaf6)), released on 18 November 2026. Settings > About names that base on every build. Everything that comes from PlxNative 0.10.1 itself (a faster Home on LG's 2020 Realtek sets, smoother player menus, seeks on sets that report no displayed frames, Continue Watching opening on your newest card, and Pause then Play while playback starts) is described in [PlxNative's 0.10.1 release notes](https://github.com/GLinnik21/plx-native/releases/tag/v0.10.1).

## What's new

- **Control FinNative from another Jellyfin client.** FinNative now shows up as a cast target in other Jellyfin apps, which can start a title on it, play and pause it, and send the arrow keys.
- **Sort a library.** A library offers a sort menu (title, date added, release date, rating, length, date watched), and Plays sorts by play count.
- **Home videos and music videos.** A home video or music video library now lists its videos and plays them, instead of coming back empty.
- **A fuller library page.** A TV library's page shows Next Up for its own shows, a movie library shows your server's suggestion rows (Because you watched, Because you like, Directed by, Starring), and each shows its own Favorites.
- **Shelves keep going.** Shelves on Home and on a library's page load more cards as you scroll, instead of stopping after the first ones.
- **Filmography on a person's page.** A person's page lists their films and shows from The Movie Database, grouped by department; a title your library holds opens straight from there. These are the new hosts FinNative contacts, api.themoviedb.org for the list and image.tmdb.org for its posters, only when you open a person's page.

## Fixed

- **Your server did not see playback.** Since 0.2.0, FinNative's playing and paused reports went out in Plex's form, so your Jellyfin server did not show FinNative as playing and did not keep the resume point while you watched. They reach the server again.

## Compatibility

- **Plays video, verified by watching it — 2021 LG sets.** One television: an LG C1, which reports platform release 6.5.3. FinNative is developed on it; the audit says what was run on it.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up is expected to start.** This binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/tiper/fin-native/blob/main/docs/release-audits/v0.2.1.md). That grades startup and says nothing about whether video plays.
- **Does not start — webOS 3.9.2 and older.** Symbols the app needs are missing there, so the process is killed before anything appears.

If your set is in the middle group, [tell us what happened](https://github.com/tiper/fin-native/issues). It working is as useful a report as it failing.

## Installing

Download **io.github.tiper.finnative_0.2.1_arm.ipk** and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). FinNative is not in the Homebrew Channel yet. You do **not** need a rooted TV. FinNative installs beside PlxNative; it is not affiliated with Jellyfin or PlxNative.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  io.github.tiper.finnative_0.2.1_arm.ipk
```

[Installing and checking a download](https://github.com/tiper/fin-native/blob/main/docs/install-finnative.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.2.1](https://github.com/tiper/fin-native/blob/main/docs/release-audits/v0.2.1.md).
