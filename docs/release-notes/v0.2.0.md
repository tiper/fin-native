# v0.2.0 — skip intros on Jellyfin, video quality and HDR on cards, Previous episodes, and PlxNative 0.10.0

This release brings PlxNative 0.10.0's new features to Jellyfin: intros and credits can be skipped automatically using your server's own markers, Previous plays the episode before, cards show a title's video quality and HDR, and Continue Watching shows each title's backdrop and logo. A favourite or Home setting changed in another Jellyfin client now reaches Home at once, and FinNative asks your server for less. It is the first release since 0.1.0, which was cut on 2026-11-03.

It is built on PlxNative 0.10.0 ([0158681](https://github.com/GLinnik21/plx-native/commit/015868116287136757e456797754fd9a846d42b4)), released on 12 November 2026. Settings > About names that base on every build. Everything that comes from PlxNative 0.10.0 itself (the player HUD gallery and HUD packages, the Yellow subtitle color, styled ASS subtitles with their own fonts, the redesigned Settings, Home hero and Library, the estimated end time, Catalan, and its playback fixes) is described in [PlxNative's 0.10.0 release notes](https://github.com/GLinnik21/plx-native/releases/tag/v0.10.0). One of those changes contacts a new host: the Player HUD gallery reads its signed list of HUDs from huds.plxnative.com, which PlxNative's project runs, at most daily.

## What's new

- **Skip intros and credits on Jellyfin.** Settings → Video & playback → **Skip intros** and **Skip credits** (Manual, Disabled or Automatic) now work for every Jellyfin viewer, using the intro and credits markers your server stores for the item (its media segments). Before, these rows stayed hidden on a Jellyfin server.
- **Previous plays the episode before.** An episode's queue now carries the episode before it, so Previous plays it wherever the episode was started from, and Next after going back resumes where that episode was left.
- **Video quality and HDR on cards.** The Home hero and the details under posters show a title's resolution (4K, 1080) and whether it is HDR or Dolby Vision, read from what your Jellyfin server stores for it.
- **Continue Watching shows backdrops and logos.** Each Continue Watching tile draws the title's backdrop with its logo, instead of falling back to the title in type.
- **Changes from another device reach Home at once.** A favourite added or removed, or a Home setting changed, in another Jellyfin client refreshes FinNative's Home straight away, over the live connection FinNative already keeps to your server.

## Fixed

- **Messages said "your Plex server".** The Dolby Vision setting, the player's conversion notes and the sign-in connection messages now name your Jellyfin server, in every language.
- **HUD packages are checked against the right version.** A HUD package names the PlxNative versions it works with; FinNative now judges that against its PlxNative base instead of its own version number, so compatible packages are not refused.

## Changed

- **FinNative asks your server for less.** Poster rows, seasons, collections, a show's page and its extras ask only for what they draw, and leaving Continue Watching takes fewer requests. The live connection to your server now runs on PlxNative's shared WebSocket client.

## Compatibility

- **Plays video, verified by watching it — 2021 LG sets.** One television: an LG C1, which reports platform release 6.5.3. FinNative is developed on it; the audit says what was run on it.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up is expected to start.** This binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/tiper/fin-native/blob/main/docs/release-audits/v0.2.0.md). That grades startup and says nothing about whether video plays.
- **Does not start — webOS 3.9.2 and older.** Symbols the app needs are missing there, so the process is killed before anything appears.

If your set is in the middle group, [tell us what happened](https://github.com/tiper/fin-native/issues). It working is as useful a report as it failing.

## Help test this release

**If you have a television other than an LG C1**, install it, play a film and an episode, and tell us what you saw. **If your Jellyfin server has intro or credits markers**, try Automatic skipping and tell us whether it skipped at the right moment.

## Installing

Download **io.github.tiper.finnative_0.2.0_arm.ipk** and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). FinNative is not in the Homebrew Channel yet. You do **not** need a rooted TV. FinNative installs beside PlxNative; it is not affiliated with Jellyfin or PlxNative.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  io.github.tiper.finnative_0.2.0_arm.ipk
```

[Installing and checking a download](https://github.com/tiper/fin-native/blob/main/docs/install-finnative.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.2.0](https://github.com/tiper/fin-native/blob/main/docs/release-audits/v0.2.0.md).
