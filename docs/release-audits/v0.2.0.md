# Release audit — v0.2.0

The evidence behind [the v0.2.0 release note](https://github.com/tiper/fin-native/blob/main/docs/release-notes/v0.2.0.md). Written for a webosbrew reviewer, a contributor auditing an old release, and us in a year. The section at the bottom is generated from the artifact that was published; everything above it was written by a person before the release ran.

FinNative's version numbers are its own: PlxNative's releases with the same numbers are a different application (`com.beb.plxnative`). This release is the first built on a PlxNative release rather than a development tree: PlxNative 0.10.0.

## Compatibility tiers, and what moved

Nothing moved since v0.1.0. The LG C1 is the only set that plays video by observation. Every other tier is the static loader check in the generated block below, which grades whether the process starts and cannot see a video plane.

## Known issues at release, with provenance

None recorded for this package.

## Deliberately not done

- No crash reports and no usage analytics: the build compiles in no Sentry DSN and no PostHog key (`telemetry: none` in the release workflow), so nothing is uploaded to Sentry either.
- No nightly channel and no project website: PlxNative's `nightly.yml` and `pages.yml` are disabled in FinNative's repository.

## Release configuration

| | |
|---|---|
| flavour | `io.github.tiper.finnative` (stable), the id users install; `FLAVOR: stable` is pinned in the release workflow's build job |
| cargo features | `RELEASE=1`, which drops `devtools` and `devtriggers` |
| telemetry | none: no endpoint is compiled in and the build step asserts the binary carries none |
| built on | PlxNative 0.10.0, its release commit [01586811](https://github.com/GLinnik21/plx-native/commit/015868116287136757e456797754fd9a846d42b4) (12 November 2026), and no upstream change after it; About prints `PlxNative 0.10.0` (`PLXNATIVE_BASE`) |
| built by | GitHub Actions, from the tag, at a path identical on every runner |
| toolchain | webOS NDK and the stable Rust release pinned in `rust-modules/rust-toolchain.toml`, as inherited from PlxNative |

Nothing else is unusual about this build.
